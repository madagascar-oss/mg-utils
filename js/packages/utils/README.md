# @madagascar-oss/utils

Every mg-utils module in one install: Malagasy number words and phone numbers.

Implements spec 0.1.0.

```sh
npm install @madagascar-oss/utils
```

```ts
import { formatPhoneNumber, numberToWords } from '@madagascar-oss/utils';
```

Prefer the single-module packages (`@madagascar-oss/words`, `@madagascar-oss/phone`) when you
need only one.
